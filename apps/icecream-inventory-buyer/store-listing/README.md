# Jora Trade — Google Play store listing assets

**Access:** Invite-only. Buyers enter a code issued by their ice cream manufacturer / supplier in BuildFlow. No public registration.

All image files are PNG, under 8 MB, and meet Play size/aspect rules.

## Start here

1. `PLAY_CONSOLE_COPY.txt` — name, short/full description, privacy URL  
2. `UPLOAD_CHECKLIST.md` — what to upload where  
3. `builds/DOWNLOADS.md` — AAB/APK links after EAS build
